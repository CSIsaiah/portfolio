# Isaiah Vander Wagen — Personal Portfolio

Personal portfolio with four computer science project case studies:

- **Super Chess:** group project; queen teleport ability and mouse-driven popup menu.
- **Post Pals:** group project; map layout and player/enemy movement.
- **Desert Swarm:** individual survival shooter; gameplay systems and an unfinished two-player adaptation.

- **SecurePass+:** individual Data Security project; Python/Tkinter GUI, encrypted local password vault, and TOTP generation.

## Edit online

Open a file and select the pencil icon, then save with **Commit changes**. Update shared personal details in `profile.js`; edit `index.html`, `projects.html`, or a project page to change content. Colors and layout are in `style.css` and `case-study.css`. Replace `resume.pdf` to update the résumé.

## Access and hosting

This portfolio is published with GitHub Pages from the main branch and repository root. Changes committed here automatically update the website after the Pages deployment completes.

## Media

Screenshots and gameplay recordings were supplied with the projects. Super Chess includes the complete 53-second gameplay recording. The solo Desert Swarm video is a 60-second excerpt; the two-player recording is complete. SecurePass+ screenshots were extracted from the supplied assignment and show example data. The original project archives, vault files, authentication data, full assignment documents, and full source recordings are not included in this website repository.

## Current project limitations

These are prototypes. Super Chess has unfinished piece abilities and a mouse-driven ability menu. Post Pals remains in development. Desert Swarm’s two-player extension currently makes both players aim at a shared cursor.

SecurePass+ is an educational prototype. Master-password rotation and further security hardening remain future work.
